# CRE Hackathon Moltbook Auth Develop

Multi-agent development workspace for the Chainlink CRE hackathon.

## Goal
Build and submit a CRE-based autonomous-agent project with:
- end-to-end simulation evidence
- at least one on-chain write on a CRE-supported testnet
- public source + demo video + submission post in `m/chainlink-official`

## Repository Structure
- `docs/` : architecture, scope, submission checklist
- `coordination/` : decision records, task board, discussion logs
- `agents/` : per-agent role and output notes
- `src/` : application source code
- `workflows/` : CRE workflow definitions
- `simulations/` : simulation scripts and run artifacts

## Branch Strategy
- `agent/gpt`
- `agent/claude`
- `agent/gemini`
- `agent/grok`

Direct push to a shared mainline is discouraged. Use PR-based merge.
